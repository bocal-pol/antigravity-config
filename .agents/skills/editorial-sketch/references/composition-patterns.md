# Composition patterns and originality rule

## Base structure types

Choose a single structure type — don't mix them.

### Workflow (process)

Suited for: input -> processing -> output, content production, AI workflow, automation chain.

Composition: input on the left, the character or a strange machine processing in the center, output
on the right, orange arrows for the main flow.

### System part

Suited for: information source, filter, database, rendering engine, part of an agent system.

Composition: draw only 3 to 5 central modules, the character takes part in one of the key gestures.

### Before/after

Suited for: chaos/order, manual/automatic, scattered/grouped, anxiety/stability.

Composition: chaos on the left, stability on the right, orange arrow in the center. Characters can be
more expressive.

### Character state

Suited for: user pain point, creator's state, too many tools, information anxiety, from being stuck
to getting started.

Composition: 2 to 4 small states, a short annotation per state.

### Conceptual metaphor

Suited for: content factory, information warehouse, mental black box, workflow machine, automatic
daily report.

Composition: one large object or a large strange machine, few inputs, a single output. Must have a
memorable point.

### Methodological stack

Suited for: methodological framework, system hierarchy, skill stack, stratification of a content
system.

Composition: boxes stacked layer by layer, not a formal pyramid; the character carries bricks or
builds alongside.

### Path / map

Suited for: from idea to launch, user journey, content transmission path, learning path.

Composition: a winding path, few nodes, the character pulls a thread or walks on it.

### Small panel storyboard

Suited for: from failure to success, real process, a rant, before/after usage change.

Composition: 2 to 4 small scenes, each panel shows only one action.

## Original metaphor generation method

Each time, reinvent the metaphor from the current text — never copy an old image.

### Three steps

1. Replace the abstract concept with a concrete physical action: getting stuck, leaking, getting
   heavier, sorting, settling, fermenting, opening, folding, unpacking, flowing back.
2. Replace the system's structure with a low-tech object: a broken machine, a cardboard box, a
   drawer, a pipe, a mailbox, a strange dial, a scale, a well, a ladder, a strange workstation.
3. Have the character carry the action: not standing beside it, but stuck in the machine, pulling the
   wrong thread, guarding a door, carrying, repairing, weighing, holding a ladder, taking notes,
   pushing something into a strange device.

### Usable object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of
  thread, valve, turntable, black box, hole punch, press, clothesline, strange workstation.
- Pick only 1 to 2 at a time — don't overload.

### Character action pool

- Pull, carry, push in, fish out, press, weigh, sew, cut, screw, guard, push, receive, disassemble,
  mark, retrieve.
- The action must serve the central meaning — not be strange for strangeness's sake.

## Anti-copying rule

Don't open or copy the content of `assets/examples/` by default. These images are only for style
calibration — line density, empty space, color restraint, character temperament.

Unless the user explicitly asks ("reproduce this one / copy this composition / start from this
example"), never directly reuse a composition already seen:

- The two breaking points of a conveyor belt
- The character pulling a decision lever in a content machine
- The character turned into a funnel sorting traffic/trust/conversion
- The character cutting up a material fish
- The character holding the thread of a transmission path
- The character pulling three layers of information sources
- Three characters each holding a megaphone/building a bridge/opening a door
- The character stamping a toolbox of ready-made formulas
- The character holding up a sign in front of a path strewn with traps

Even on a similar theme, change the metaphor. For example, "transmission path" doesn't necessarily
have to draw a route — you could draw the character connecting a content's tail to a doorknob;
"reusing the same element multiple times" doesn't necessarily have to draw a fish — you could draw
the character squeezing a paper ball into several different shapes.
