# Timeline — Timeline

## Effect
Horizontal timeline, dated milestones along a guide line.

## Imposed structure (non-negotiable)
- Continuous timeline
- Evenly spaced markers/milestones, date + event labels
- Optional icon per milestone

## Positive Prompt (English skeleton)
`timeline infographic of {{subject}}, horizontal chronological line with evenly spaced labeled
milestones, dates and short descriptions, clean modern design, consistent icon style`

## Negative Prompt
`non-chronological layout, missing dates, cluttered, watermark, blurry`

## Variables to collect
1. Subject/events to put on a timeline?
2. Number of milestones?

## Combinable with
- `infographic`, `comparison`

## Example
Subject "company history" → milestones for 2010 founding, 2015 funding round, 2020 IPO.
