# Infographic — Infographic

## Effect
Structured educational layout, numbered sections, icons, clear visual hierarchy.

## Imposed structure (non-negotiable)
- Title at the top, content blocks in a grid/columns
- Simple flat icons, consistent 3-4 color palette
- Progress arrows between sections

## Positive Prompt (English skeleton)
`educational infographic about {{subject}}, clean structured layout with numbered sections,
simple flat icons, consistent 3-4 color palette, clear visual hierarchy, connecting arrows,
modern flat design`

## Negative Prompt
`cluttered text-heavy layout, inconsistent style, photographic realism, watermark, blurry`

## Variables to collect
1. Subject/theme to explain?
2. Number of key points/sections (3 to 6)?

## Combinable with
- `diagram`, `dashboard`, `handwritten`

## Example
Subject "water cycle" → 5 numbered sections with evaporation/condensation/precipitation icons.
