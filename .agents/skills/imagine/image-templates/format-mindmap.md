# Mind map — Mindmap

## Effect
Tree-structured mind map, central idea radiating into colored branches.

## Imposed structure (non-negotiable)
- Single central node
- Curved branches radiating to sub-topics, one color per branch
- Optional icons on leaf nodes

## Positive Prompt (English skeleton)
`mind map of {{subject}}, central node radiating curved colored branches to sub-topics,
hand-drawn digital illustration style, organized hierarchical layout, clean background`

## Negative Prompt
`linear list layout, no branching, cluttered, watermark, blurry`

## Variables to collect
1. Central idea?
2. Main branches to include (3-6)?

## Combinable with
- `diagram`, `handwritten`

## Example
Subject "marketing content plan" → central node, branches for SEO/social/email/paid.
